# Proposal

## Why

The control center presents its workflows as undifferentiated text buttons and uses an unnecessary underscore in the wordmark. Operators need stronger orientation, recognizable workflow icons and a compact technical presentation without adding visual noise.

## What Changes

- Remove the wordmark underscore and introduce a restrained product mark.
- Give the five work areas thematic leading icons, a clear active state and concise localized guidance.
- Arrange navigation as a compact desktop rail and a fully labeled responsive mobile layout; retain flat content and primary-action visibility.
- Refine typography, spacing, focus and status accents using existing local shadcn tokens.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `local-control-center`: recognizable, accessible navigation and responsive operator layout.

## Impact

Local web shell/styles, browser assertions and platform-specific visual baselines, and canonical UI guidance. No new dependencies, commands, provider calls, migration behavior, data formats or destructive actions. Retry, resume, identity and mutation safeguards remain unchanged.
